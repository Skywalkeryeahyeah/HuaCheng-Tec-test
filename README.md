# HuaCheng Technology Website

HuaCheng 科技公司官网 Web 前端项目，基于现代前端技术构建，包含企业介绍、产品展示、业务服务、新闻资讯与联系方式等模块，注重简洁的页面设计、良好的交互体验与响应式布局。

## ✨ Features

* 🏢 企业信息展示
* 📦 产品与服务介绍
* 📰 新闻与资讯模块
* 📱 响应式页面布局
* 🎨 简洁现代的 UI 设计
* ⚡ 流畅的页面交互体验

## 🛠 Tech Stack

* Git & GitHub

## 🚀 Getting Started

克隆项目：

```bash
git clone <your-repository-url>
```

进入项目目录：

```bash
cd HuaCheng-Web
```

安装依赖：

```bash
npm install
```

启动项目：

```bash
npm run dev
```

## 🎯 Project Purpose

该项目用于展示 HuaCheng 科技公司的品牌形象、核心业务与产品服务，同时作为 Web 前端开发实践项目，涵盖页面布局、组件开发、交互设计与响应式适配等内容。
